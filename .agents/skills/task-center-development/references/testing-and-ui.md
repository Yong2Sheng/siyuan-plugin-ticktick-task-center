# 测试与界面参考

仅在任务涉及 Svelte 交互、控制器、异步状态、日期、布局或测试策略时读取。

## 测试选择

- 领域规则：在对应 `src/domain/*.test.ts` 覆盖合法值、非法值和边界。
- 任务卡片：按创建、解析、提交、编辑、删除、渲染和生命周期的职责选择相邻测试，不只验证最终 HTML。
- 任务中心：分别验证 SQL/聚合、筛选、控制器状态、页签生命周期和视图事件。
- 知识功能：覆盖索引解析、文档树扫描、嵌套任务边界、并发属性写入与复核、复习调度、保存失败和重新扫描保留进度。
- 思源 API：用 `src/test/siyuan.ts` 或现有依赖注入替代真实写入；只有用户明确允许时才对真实空间进行写测试。
- 回归测试应复现用户实际路径，不写只匹配实现细节或固定文案的脆弱断言。

## 高风险边界

- 创建/编辑多步写入：中途失败、回滚失败、更新时间冲突和重复提交。
- 可选字段：有值时保留或要求，清空时删除旧属性，旧任务缺失时兼容。
- 异步控制器：销毁后的回调、旧响应覆盖、重复扫描/保存、失败后重试和加载状态复位。
- 日期：使用本地日期而非隐含 UTC，覆盖午夜、跨月、跨年和时区偏移。
- 安全目标：只接受既有规则允许的 TickTick / 滴答清单、思源或 HTTPS 目标，不因界面便利放宽验证。
- 知识扫描：不在启动、聚焦或切换页签时隐式触发；新文档属性写入必须立即读取复核。

## UI 判断

先确定状态所有者，再修改组件。检查：

- 浅色与深色主题变量下的对比度，不给 Emoji 强制着色。
- 中英文切换后的按钮宽度、空状态、错误提示和日期文本。
- 宽屏与窄屏的滚动、换行、弹窗高度、内容截断和固定区域挤压。
- 鼠标与键盘操作、焦点进入/恢复、Escape 和关闭按钮。
- 任务中心刷新、筛选、搜索、状态变更和来源导航后的选中与滚动状态。

## 验证顺序

1. `CI=true pnpm vitest run <相关测试文件>`
2. `CI=true pnpm run check`
3. 影响多个模块或公共行为时运行 `CI=true pnpm test`
4. `CI=true pnpm build`
5. `git diff --check`
